Trustnet

MCP connector documentation

Trustnet is a private recommendation network. A member asks people they trust for a doctor, a restaurant, a plumber, keeps what those people answer, and recommends back. There are no public reviews and no algorithmic feed — every recommendation in a member's library came from someone they chose.

This connector lets an assistant read a member's own library and, when the library does not already answer, draft a question to one of their circles.

A connector cannot message anyone. draft_question writes a draft and returns a link. The member opens it, sees exactly who would receive exactly what, and presses send themselves. There is no code path from this server to a circle member.

The people in a circle are real, and they are in it because the member trusts them. That is the asset the product is made of, and an assistant that could message them unprompted would spend it.

Endpoint

URLhttps://trustnetsocial.netlify.app/mcp
TransportMCP streamable HTTP. POST JSON-RPC 2.0.
Protocol2025-06-18, and 2025-03-26 accepted
AuthAuthorization: Bearer <connector token>
Capabilitiestools. No resources, no prompts, no sampling.

Authentication

A member connects once at trustnetsocial.netlify.app/connect. That page states what the connector may and may not do, and issues a token. The member pastes it into the assistant.

  • Tokens are 256 bits of random, and only a sha256 of the token is stored — the plaintext exists once, on screen.
  • A member can revoke any token from the same page, and revocation is immediate.
  • The token resolves to a member and then a real member session is minted; every read runs through it, so row-level security in the database decides what is visible, not application filtering.

An unknown or revoked token gets JSON-RPC error -32001 with HTTP 401 and a message naming the reconnect URL.

Tools

search_library

Searches the member's own saved recommendations — hybrid retrieval with a rerank, so "somewhere to eat in Puglia with children" matches on meaning and on proper nouns. Returns the member's own note and rating. { query, limit? }, limit defaults to 10, maximum 40.

list_circles

The member's circles, by name and domain, with a count of people in each. Names and counts only — the people in a circle, and their phone numbers and email addresses, are never exposed to a connector. No arguments.

draft_question

{ circle_id, text }. Writes a draft and returns a confirm_url valid for thirty minutes. Sends nothing. The response carries sent: false and a line for the assistant to relay, so the member is told plainly that nothing has gone out. A circle id that does not belong to the member returns no_such_circle, because the lookup runs under the member's own session.

get_answers

With no argument, the member's ten most recent questions and how many answers each has. With { question_id }, the answers themselves — grouped, so one place recommended by three people reads as one entry with three voices.

Example

curl -s https://trustnetsocial.netlify.app/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TRUSTNET_TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"search_library",
                 "arguments":{"query":"where to eat in Puglia"}}}'

Rate and cost

No published rate limit beyond ordinary abuse protection. search_library and get_answers each perform a model call, so an assistant should search once and reason over the result rather than polling.

Errors

CodeMeaning
-32001Not connected, or the token was revoked. HTTP 401.
-32601Unknown JSON-RPC method.
-32700Malformed JSON.

A tool that fails returns a normal result with isError: true and a reason, rather than a protocol error — so an assistant can tell the member what went wrong instead of dropping the conversation.

Data handling

What Trustnet stores, where it is kept and who else it passes through is set out in the privacy policy, which names every third party by name. A connector adds no new storage: it reads what the member already has, and writes only drafts the member either sends or discards.

Status

Trustnet is an MVP in private testing. The terms of service say plainly that it can break and that data can be lost; this connector is held to the same honesty.
